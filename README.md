# CAPRION / NEON PROTOCOL (Tkinter Edition)

A native Python desktop recreation of the CAPRICORN cyberpunk wallpaper.

## Features
- Real-time system audio visualizer (using `soundcard` and `numpy`)
- Reactive "Living Mask" that tracks mouse movement
- Multi-image block glitching effects
- Terminal takeover events
- Live clocks, calendar, and diagnostics

## How to Run
1. Install dependencies: `pip install pillow numpy soundcard`
2. Ensure your images are in the `assets/` folder.
3. Run: `python main.py`

*(Press `Escape` to close the app, press `Space` to trigger a glitch)*
